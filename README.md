# Spam Classifier - Logistic Regression

This is a Spam Email Classifier built using *Logistic Regression Algorithm*.

## Accuracy
*77.78%*

## Features
- Clean and preprocess email data
- Train Logistic Regression model
- Predict if an email is Spam or Ham
- Deployed with Streamlit

## How to Run
1. Install requirements: pip install -r requirements.txt
2. Run app: streamlit run app_lr.py

## Dataset
email_data.csv
